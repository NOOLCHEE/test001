## 스도쿠 순위 기록

순위 기록은 Node.js 서버가 제공하는 API를 통해 `data/leaderboard.json`에 저장됩니다. 난이도별 상위 10개 기록은 같은 서버에 접속하는 모든 브라우저에서 공유되며, 닉네임 선호값만 각 브라우저에 저장됩니다.

### 실행

Node.js 18 이상에서 다음 명령으로 서버를 실행한 뒤 `http://localhost:3000`을 여세요.

```sh
npm start
```

`PORT` 환경 변수로 포트를 지정할 수 있습니다. 서버 프로세스는 하나만 실행하는 구성을 전제로 하며, 배포 환경에서 서버 파일 시스템이 임시 저장소라면 재시작·재배포 시 기록이 사라질 수 있습니다. JSON 파일 저장 방식은 서버 여러 대가 동시에 같은 파일을 쓰는 환경에도 적합하지 않습니다. 또한 완성 시간은 현재 브라우저에서 보내므로 공개 서비스에서는 조작될 수 있습니다.

### Cloudflare 배포 참고

저장소 전체를 Workers 정적 자산 디렉터리로 지정하는 경우 `.assetsignore`가 `node_modules`와 서버 전용 파일이 자산 업로드에 포함되는 것을 막습니다. 이 설정은 `workerd` 바이너리가 정적 자산 크기 제한을 넘는 배포 오류를 방지합니다.

정적 자산 업로드만으로는 `server.js` API가 실행되지 않습니다. Cloudflare에 순위 API를 함께 배포하려면 Workers용 API로 옮기고 JSON 파일 대신 Workers에 맞는 영속 저장소를 연결해야 합니다. 현재 JSON 파일 기반 API는 `npm start`로 실행되는 Node.js 서버용입니다.
